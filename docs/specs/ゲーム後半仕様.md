# ゲーム後半仕様（2曲目カードからENDまで）

更新日：2026年11月21日

## この仕様書の範囲

本編画面 `/game.html`（開発時は `/game` も可）で2曲目「過去の音楽劇メドレー」のカードを表示した後から、
最後の台詞とEND画面を表示するまでを扱います。ブラウザで使用する台詞は
`static/data/scenario.json`と再生処理を正とし、[script.md](script.md) は現在の実装に合わせます。

2曲目カードまでの進行は [ゲーム冒頭仕様.md](ゲーム冒頭仕様.md)、タイトル〜ENDの総合仕様は [実装済み仕様.md](実装済み仕様.md) を参照します。

演奏会で演奏する2曲目、3曲目、第3部の楽曲はゲーム内では再生せず、5秒間のカードで
演奏区間を表します。曲カードは操作では進めず、5秒後に自動で進めます。

## 全体の進行

1. 黒画面に2曲目カードを表示します。
2. 5秒後にカードを消し、ホール背景を明転しながら「朝日溢れる回廊_2」を流して2曲目後の台詞へ進みます。
3. クロコが手拍子を促した後、3曲目「宝島」のカードを表示します。
4. 朝日BGMと画面を同時に1.5秒で消し、完全な黒と音量0が同時になってからカードを表示します。
5. 宝島のカード後も、ホール背景は`hole.png`を使用します。「朝日溢れる回廊_2」を1秒で再開し、「でしたら、もう帰る必要はありません」の表示完了時に即停止します。
6. 「このまま過去に留まりましょう。」から主人公の「ずっと、ここに……」と、続く迷いのカメラ演出中までクロコを`smirk`で表示します。カメラ演出は背景とクロコが連動する2.8秒のズームイン、3秒の静止、4秒の遅い横揺れ、3秒のズームアウトで表し、横揺れは1600×900で左右24pxまで動かします。ズームインとズームアウトの開始時に革靴SEを鳴らし、「迷う必要はありません。」の表示時に`default`へ戻します。
7. 主人公の「いいや」「だって」「あの時も前に進んでたから。」を1つずつ表示します。
8. 3つ目は文字だけを鮮明な赤色にし、押した直後から「悠久の大地」をフェードなしで音量34%で再生し、クロコを驚き顔へ切り替えます。
9. 「それに——」と「『現在（いま）も楽しいってところを見せてあげる！』」を別画面で表示し、後者の選択後にクロコを`grin`へ切り替えます。その後、12秒で暗転し、「悠久の大地」も暗転と同じ変化曲線で小さくして停止します。画面が完全な黒になる時点と音量0になる時点を揃えます。カードは5秒表示します。
10. 第3部後の「どうだった？」を選んだ後、朝日BGMを4秒かけて音量34%まで上げます。
11. 「やっぱり楽しんでたんじゃない」の後、朝日BGMを4秒で停止してからクロコの告白を表示します。
12. 主人公の「大丈夫だよ！」を選んだ後に「星の名残り」を4秒で音量34%まで上げます。選択演出が終わってから2秒空け、「時間はそこに在るだけでいい。」を表示します。この台詞を選んだ後も、選択演出が終わってから2秒空けて次の台詞を表示します。
13. 「なかなかの解釈ですね。もちろんわかっていましたよ。」と「よく考えれば当然のことです。」ではクロコを`blush`で表示します。後者の後は2.5秒空け、ボックスと表情を切り替えて「仕方ないですね」を表示します。
14. 「仕方ないですね」の後はテキストボックスを消し、1.2秒静止します。その後、背景とクロコへ3秒でズームし、ズーム完了後に表情とボックスを切り替えて「人類の未来は、この私にお任せください！」を表示します。
15. 最後の台詞後は4秒で完全な黒へ暗転し、何もない黒画面を1秒保ってから、作品名とENDを3秒でフェードインします。その後、`tap to end`を押すと1.8秒で画面とBGMを消してタイトルへ戻ります。

## カードのタイマー

- 曲カードには「タップで進む」を表示しません。
- カードの表示演出が終わってから5秒を数え、自動で次の場面へ進みます。
- カード表示中のタップ、クリック、Enterキー、Spaceキーでは進みません。
- タイトル復帰確認中はタイマーを停止し、キャンセル後に残り時間から再開します。
- 1曲目を含むすべての曲カードが、5秒後の自動進行だけを使用します。

## テキストと立ち絵

- 主人公の台詞は、1600×900のPC表示で画面幅72%の1行ボックスへ表示し、長い台詞だけ
  最大2個へ分けます。文字、高さ、角丸も画面全体と同じ倍率で縮小します。
- 台本の1行に複数のかぎ括弧がある場合は、かぎ括弧ごとに別の台詞として順番に表示します。
- 半角括弧に書かれた赤文字、BGM、ズームの指示は画面へ文章として表示しません。
- クロコは明るい場面で`grin`や`smile`、過去へ誘う場面で`smirk`、主人公への感謝を受け止める場面で`blush`、赤い主人公台詞を選んだ後の動揺で`surprise`、存在意義を見失う場面で`sad`を使用します。
- 新しい表情を後ろへ不透明のまま置き、前の古い表情だけを600ミリ秒でフェードアウトします。

## BGM

| BGM | 配信ファイル | 音量 | 主な使用箇所 |
| --- | --- | --- | --- |
| 朝日溢れる回廊_2 | `static/audio/bgm/corridor.mp3` | 34% | 2曲目後から宝島前、宝島後から提案直前、第3部後 |
| 悠久の大地 | `static/audio/bgm/eternal-earth.mp3` | 34% | 現在を選ぶ主人公の台詞以降 |
| 星の名残り | `static/audio/bgm/star-remnants.mp3` | 34% | クロコの告白に答えた後からEND |

ブラウザの自動再生制限で「星の名残り」を開始できない場合も、選択演出後の2秒の間を保って
次の台詞へ進みます。それ以外のBGMを開始できない場合も、台詞と画面遷移は停止しません。
タイトルへ戻る場合は、再生中のすべてのBGMとSEを停止します。

BGMの音量変更には`src/ts/audio-gain-controller.ts`（Vite ビルドで `dist/assets/` へ出力）の`GainNode`を使います。
Web Audio APIを利用できない場合は`HTMLAudioElement.volume`へ切り替えます。
iPhoneのChromeなどで音声処理が停止している場合は、プレイヤーの操作時に再開します。
SEはBGM用の`GainNode`を通さず、各音源に設定した音量で再生します。

## END画面

- 最後の台詞を押すまで、クロコの立ち絵と台詞を表示します。
- 押した後も台詞、立ち絵、ホール背景は不透明のまま残し、手前の黒い幕だけを4秒かけて
  フェードインします。完全な黒になってから、背面の台詞と立ち絵を非表示にします。
- 文字のない黒画面を1秒保ち、その後、作品名と`END`を3秒かけて中央へ表示します。
- 「星の名残り」はループさせず、そのまま自然再生を続けます。
- 左上の「タイトルへ」は隠し、合計8秒の演出完了後に、タイトル画面と同じ明滅の
  `tap to end`を表示します。
- END画面のどこを押しても反応し、決定SEは鳴らしません。
- 押した後は「星の名残り」と画面を1.8秒で消し、タイトルへ戻ります。

## 確認方法

```sh
npm run typecheck
npm run build
npm run test:unit
```

自動テストでは、素材の存在、全章の順番、4枚の曲カード、赤文字、演出ID、最終章の
END到達を確認します。Playwrightでは、タイトルからENDを経てタイトルへ戻るまでを確認します。
