## 現在遊べる範囲

タイトル画面から本編を開始し、最後の「人類の未来は、この私にお任せください！」と
END画面まで遊べます。

演奏会で演奏する1曲目、2曲目、3曲目、第3部の楽曲そのものは再生しません。
1曲目から第3部までの曲カードは、操作を受け付けず5秒後に自動で進みます。

## 画面とURL

| 画面 | URL | 主な役割 |
| --- | --- | --- |
| タイトル画面 | `/`（`index.html`） | 作品名を表示し、BGM操作とゲーム開始を受け付ける |
| 本編画面 | `/game.html`（開発時は `/game` も可） | 台本冒頭からEND画面までを進行する |

どちらも16:9の比率を保ち、スマートフォンの横向き画面で遊べるようにします。
縦向きや16:9より横長の画面でも、ゲーム画面全体を中央に収めます。
タイトルと本編は1600×900を基準にし、文字、ボックス、余白、装飾を含む画面全体を
同じ倍率で縮小します。スマートフォン専用の文字拡大は行いません。

タイトルと本編のブラウザアイコンには、暗い茶黒の背景へ金色のメトロノームと
反復を示す円弧を配置します。通常のfavicon、512ピクセルの原版、iPhoneの
Apple Touch Iconは、すべて`static/images/icons`から配信します。

## タイトル画面の見た目

- 背景には`music_room.png`を使い、暖色、周辺の暗さ、右側から差し込む夕焼けをCSSで重ねます。
- タイトルは「青春再演劇場」と「リプライズ」の2段です。画面上端から42%の位置を中心にし、下へ金色の飾り線を置きます。
- 左上のスピーカーボタンは直径3.75cqw、アイコンは2cqwとし、スマートフォンでも本文文字と近い大きさにします。
- 背景は800ミリ秒、タイトルは200ミリ秒待ってから650ミリ秒、飾り線は350ミリ秒待ってから650ミリ秒で表示します。
- 夕焼けは8秒で往復します。手前の微粒子8個は10秒、奥の微粒子7個は14秒で移動します。
- `tap to start`は画面下から14%の位置に置き、3.8秒周期で透明度8%から100%まで明滅させます。
- 右下の音源クレジットから素材名、制作者、配布元を確認できます。クレジットの下部には、音源ファイルの抽出・別用途利用を禁止する案内を表示します。クレジット操作はゲーム開始処理へ伝えません。
- 夕焼け、微粒子、飾り線は読み上げ対象から外します。外部フォントや外部JavaScriptライブラリは使いません。

## 入力とテキスト表示

### 通常の台詞と地の文

- 画面下部の画面幅96%のテキストボックスに、最大2行で表示します。
- 本文、話者名、余白は1600×900のPC表示を基準に、ゲーム画面と同じ倍率で縮小します。
- 1文字45ミリ秒で表示し、表示途中の操作では残りをすぐに表示します。
- 全文表示後の次の操作で、次の文章へ進みます。
- タップ、クリック、Enterキー、Spaceキーを使用できます。
- スマートフォンのタップ時に黒いハイライトを表示しません。
- 話者がいる場合は、本文ボックスの左上に名前を表示します。
- 同じ話者の連続台詞、地の文の続き、長文の次ページでは、本文だけを更新して
  テキストボックス本体を表示したままにします。
- 話者が別の人物へ変わるとき、地の文と人物が切り替わるとき、主人公の中央ボックスと
  切り替わるときだけ、メインのテキストボックスをフェードさせます。
- `???`から`クロコ`への名前登録は同一人物なので、本文ボックスと名前枠は消しません。
  `???`を500ミリ秒で消し、文字のない名前枠を150ミリ秒保ち、`クロコ`を500ミリ秒で表示します。

### 主人公の台詞

- 画面中央に、PC表示で画面幅72%の1行固定ボックスを最大2つ縦に表示します。
- 高さ、文字、角丸もゲーム画面と同率で縮小し、角ばった長方形を保ちます。
- 主人公の台詞を表示している間は、ボックス内だけをタップ対象にします。
- 2つのボックスはどちらを押しても同じ次の場面へ進みます。
- 押した瞬間に決定SEを鳴らし、選んだボックスを少し膨らませて約420ミリ秒で消します。
- 選ばなかったボックスは約220ミリ秒で、選んだボックスより先に消します。
- ホバーやフォーカスによる色の変更と、逆三角形の送りアイコンは表示しません。
- 「あの時も前に進んでたから。」だけは、台本指定に従って赤色で表示します。

`sourceText`の原文は変えず、画面上の表示だけを次のように分けます。

| 「急に責任が重い。うーん……じゃあ、クロコ」 | 「急に責任が重い。」「うーん……」「じゃあ、クロコ」の3画面 | 3画面目の後に名前登録へ進む |
| 「ああ、これも懐かしい。曲だけじゃない。練習して、衣装を用意して、みんなで一つの舞台を作ったことまで思い出したよ」 | 最初の2文を2個のボックス、残りを次の2個のボックスとして2画面で表示 | 1画面目では次の表示へ進み、2画面目の後に次の台詞へ進む |
| 「あの時も前に進んでたから。」 | 文字だけを鮮明な赤色で表示 | 選択直後に「悠久の大地」を開始し、その後クロコを`surprise`へ変更する |
| 「それに——『現在（いま）も楽しいってところを見せてあげる！』」 | 「それに——」と「『現在（いま）も楽しいってところを見せてあげる！』」の2画面 | 1画面目では表情を変えず、2画面目の選択後にクロコを`grin`へ変更する |

| 「仕方ないですね」と「人類の未来は、この私にお任せください！」 | 前者のボックスを消して1.2秒静止し、背景とクロコへ3秒でズームしてから後者を表示 | ズーム中にクロコを`grin`へ変更する |

### 曲名カードと第3部カード

- 曲カードには「タップで進む」を表示しません。
- 1曲目、2曲目、3曲目、第3部のカードは、表示から5秒後に自動で進みます。
- 曲カード表示中のタップ、クリック、Enterキー、Spaceキーでは進みません。
- タイトル復帰確認を開いている間はタイマーを止め、閉じた後に残り時間から再開します。
- すべてのカードは、場面を暗転してから1秒で表示し、5秒後に1.2秒で消します。
- カードが消えた後、黒画面の裏で背景を交換し、次の場面を1.5秒で明転します。
- 1曲目、2曲目、3曲目前の暗転は1.5秒です。ポップスステージ前だけは12秒かけて暗転します。
- ポップスステージ前は、黒幕とBGMへ同じ緩急のカーブを使い、暗転完了時に音量も0にします。

### 本編からタイトルへ戻る操作

- 本編左上の「タイトルへ」を押すとキャンセルSEを鳴らし、確認画面を表示します。
- ボタンは上端と左端から1.25cqwの位置に置き、本文と同じ文字サイズ、上下0.25em・左右0.6emの余白にします。
- マウスを重ねても色や背景を変えません。キーボード操作時のフォーカス表示は残します。
- 確認画面には「キャンセル」と「タイトルに戻る」の2つのボタンを表示します。
- 確認中は文章の逐次表示と曲カードのタイマーを止めます。キャンセル後は止めた位置から再開します。
- 「キャンセル」またはEscapeキーで確認を閉じ、キャンセルSEを鳴らします。
- 「タイトルに戻る」を選ぶと、すべてのBGMとSEを止めて決定SEを再生し、その後に`/`へ戻ります。
- 確認画面ではTabキーの移動を2つのボタン内に保ちます。

## 登場人物と立ち絵

- クロコの立ち絵は画面中央に配置し、頭から腰付近までが大きく見えるようにします。
- 初登場時は革靴SEを鳴らし、約1.5秒でフェードインします。
- 初登場開始から2秒間は文章送りを停止します。
- 2枚の立ち絵を重ね、`default`、`smirk`、`smile`、`grin`、`surprise`、`sad`、`blush`を切り替えます。
- 新しい表情を後ろへ不透明のまま置き、前の古い表情だけを約600ミリ秒で消します。
- 表情画像の読み込みとデコードを済ませてから切り替え、前面フェードの完了までは
  次の文章送りを待機します。画像を読み込めない場合は直前の表情を残します。
- 「クロコ。登録しました。」の後に、`???`を500ミリ秒で消し、150ミリ秒の空白後に
  `クロコ`を500ミリ秒で表示します。名前枠の大きさは変えず、立ち絵は同時に`grin`へ変更します。
- 主人公の「え？」では表情を変更しません。
- 「このまま過去に留まりましょう。」から主人公の「ずっと、ここに……」と迷いのカメラ演出中まで`smirk`を保ち、「迷う必要はありません。」の表示時に`default`へ戻します。
- 「あの時も前に進んでたから。」を選ぶまでは`default`を保ち、選択後に`surprise`へ変更します。
- 現在の楽しさを見せる決め台詞を選んだ後は、`grin`へ変更します。

## BGMとSE

| 用途 | 動作 |
| --- | --- |
| タイトルBGM | 音量30%でループし、ゲーム開始時に1.8秒で停止する |
| メトロノームBGM | 音量7%から38%まで5秒で上げ、1曲目カード前の1.5秒暗転と同時に停止する |
| 朝日BGM | 指定台詞の選択後、音量0から34%まで4秒で上げ、2曲目前の暗転で停止する |
| 後半の朝日BGM | 2曲目後に1秒で再開し、宝島前の1.5秒暗転で停止する。宝島後に1秒で再開し、「でしたら、もう帰る必要はありません」の表示完了時に即停止する。第3部後は「どうだった？」の選択後に4秒で再開し、告白前に4秒で停止する |
| 悠久の大地 | 赤い主人公台詞を押した直後、フェードなしで音量34%から始め、第3部前の12秒暗転と一緒に停止する |
| 星の名残り | 「大丈夫だよ！」の選択後、4秒で音量34%まで上げる。フェード開始から2秒後に次の台詞を表示し、tap to end後は1.8秒で停止する |
| 決定SE | ゲーム開始、主人公の台詞選択、タイトル復帰で使用する |
| キャンセルSE | タイトル復帰確認の表示とキャンセルで音量80%で使用する |
| 泡SE | 明るい海へ切り替えるときに使用する |
| 革靴SE | クロコの初登場時に音量80%で使用する |
| 迷いの革靴SE | 背景とクロコのズームイン開始時とズームアウト開始時に、音源の先頭から再生する |

ブラウザの自動再生制限によってBGMを再生できない場合も、画面遷移や文章送りは
停止しません。タイトルBGMは、ユーザーが押せるスピーカーアイコンを再生手段として
用意します。

すべてのBGMはWeb Audio APIの`GainNode`で音量を管理します。iPhone Chromeを含む
スマートフォンではクリック時に停止中の音声出力を再開します。Web Audio APIを
使用できないブラウザだけ、`audio.volume`による音量変更へ戻します。SEは従来どおり
`audio`要素から直接再生します。

## END画面

- 最後の台詞を選ぶまでは、台詞ボックス、クロコ、`hole_stage.png`を表示します。
- 選択後も台詞、クロコ、背景の不透明度は変えず、その手前へ黒い幕だけを4秒かけて
  フェードインします。
- 黒い幕が完全に不透明になってから、背面の台詞とクロコを即座に非表示にします。
- 完全な黒画面を、作品名や`END`を表示せず1秒間維持します。
- その後、作品名と`END`を3秒かけてフェードインします。
- 暗転4秒、黒画面1秒、文字のフェード3秒が終わるまでは`tap to end`を操作できません。
- `tap to end`はタイトル画面の`tap to start`と同じ周期で明滅します。
- ボタンは画面全体を覆い、文字の上以外をタップ、クリックしても反応します。
- EnterキーとSpaceキーでも操作できます。決定SEは鳴らしません。
- 操作後は画面と「星の名残り」を1.8秒で消し、タイトル画面へ戻ります。

## 台本データと再生処理

- ブラウザで使用する台詞と演出の正本は、`static/data/scenario.json`と再生処理です。
- `script.md`は人が読みやすい台本資料として、現在の実装に合わせて更新します。
- 現在実装している範囲は`static/data/scenario.json`へ構造化して登録します。
- `sourceText`には原文を保存し、表示上の分割だけを`pages`、`lines`、`linePages`へ書きます。
- 台本で1行に複数のかぎ括弧がある場合は、各台詞を順番に別画面で表示します。
- 半角括弧内の赤文字、BGM、ズームなどの指示は台詞に含めず、演出IDへ変換します。
- 発話台詞の`speakerId`で実際の人物を判定し、表示名が変わっても同一人物なら
  テキストボックスを固定します。
- 章、台詞、曲名カードの順番とデータ検証は`src/ts/scenario-runtime.ts`（Vite ビルドで `dist/assets/` へ出力）が管理します。
- `scenario.json`はversion 2とし、音源の`kind`、曲カードの`cardVariant`、演出IDを明示します。
- 入力可能な状態は`src/ts/game-state-controller.ts`、台詞表示は
  `src/ts/game-dialog-view.ts`、演出IDと実行処理は演出カタログとランナーが管理します。
- `src/ts/game.ts`は各モジュールを接続し、背景、立ち絵、音声、画面遷移を調整します。
- BGMのフェードと音声環境の切り替えは`src/ts/audio-gain-controller.ts`が担当します。
- 背景と音源はシナリオ内の素材一覧から読み込み、未登録のIDは開始前にエラーにします。
- シナリオを読み込めない場合は、原因とタイトルへ戻る操作を本編画面に表示します。

## 確認方法

ローカル起動と自動テストの詳細手順は [development.md](../development.md) を参照します。

```sh
nix develop
./scripts/check.sh
```

仕様書を更新した場合は、次の点も確認します。

- このファイルから参照するMarkdownファイルがすべて存在すること
- Markdownの表で列数がずれていないこと
- 4枚のカードについて、暗転、1秒の登場、5秒の表示、1.2秒の退場、1.5秒の明転が記載されていること
- `hole.png`と`hole_stage.png`の使用開始位置が入れ替わっていないこと
- 台詞分割、表情変更、BGM開始・停止の位置が`scenario.json`と一致すること
- [script.md](script.md) や非公開の企画原典（`private/docs/`）の本文を仕様書整理のために変更していないこと
