# ゲーム画面仕様（2曲目カードまで）

更新日：2026年11月21日

## この仕様書の範囲

この仕様書には、本編画面 `/game.html`（開発時は `/game` も可）を表示してから、2曲目「過去の音楽劇メドレー」の
曲名カードを表示するまでの流れをまとめます。

1曲目と2曲目の楽曲そのものはゲーム内では再生せず、
曲カードはすべて5秒後に自動で終了扱いとします。2曲目カード以降の進行は
[ゲーム後半仕様.md](ゲーム後半仕様.md)を参照します。

タイトル画面と本編へ移るまでの仕様は[開始画面仕様.md](開始画面仕様.md)、
全体の総合仕様は[実装済み仕様.md](実装済み仕様.md)を参照します。

## 使用する画面とURL

| 画面 | URL | 主な役割 |
| --- | --- | --- |
| 本編 | `/game.html`（開発時は `/game` も可） | 台本冒頭から2曲目の曲名カードまで進める |

本編画面は16:9の比率を保ちます。

- スマホの横向き画面でも、必要な表示が画面内に収まるようにします。
- 1600×900のPC表示を基準にし、文字、ボックス、余白、装飾を含む全要素を同率で縮小します。
- 端末が16:9より横長の場合は、高さに合わせて左右に暗い余白を表示します。
- 縦向きの場合は、16:9のゲーム画面全体を縮小して中央に表示します。
- `safe-area-inset`を使用し、ノッチやホームインジケーターとの重なりを避けます。
- 画面外へのスクロールは発生させません。

## 全体の進行

1. 本編を黒い画面から約1.5秒かけてフェードインします。
2. フェードイン後、メトロノームBGMと最初の文章表示を開始します。
3. プレイヤーの操作に合わせ、台本冒頭を全10表示で進めます。
4. 8番目の表示へ進むとき、泡SE、背景のクロスフェード、小さな泡の演出を開始します。
5. 10番目の表示後にもう一度進めると、海背景とメトロノームBGMを1.5秒で暗転・停止します。
6. 黒画面に1曲目の曲名カードを1秒で表示し、5秒間表示します。
7. カードを1.2秒で消し、背景を昼過ぎの音楽室へ切り替えて1.5秒で明転します。
8. `script.md`の「1曲目後」を、主人公とクロコの台詞を切り替えながら表示します。
9. 名前登録時に話者名を「???」から「クロコ」へ切り替えます。
10. 最後の台詞後に朝日BGMと画面を1.5秒で暗転し、黒画面に2曲目の曲名カードを1秒で表示します。
11. 2曲目の曲名カードを表示し、後半の再生処理へ引き継ぎます。

## 本編冒頭

### 本編開始時

- 最初の背景には、暗い水中画像を使用します。
- `/game.html` を開いた直後は黒い幕を重ね、約1.5秒かけてフェードインします。
- フェードインが終わってから、最初の文章を表示します。
- 同じタイミングで、メトロノームBGMの再生を試みます。

### テキストボックス

- テキストボックスは画面下部に配置し、画面幅の96%まで広げます。
- 本文を表示する領域は、ちょうど2行分の高さに固定します。
- 本文、話者名、余白は1600×900のPC表示を基準に、画面全体と同じ倍率で縮小します。
- 話者がいる場合は、本文ボックスの左上に話者名を表示します。
- 地の文では話者名を表示しません。
- 同じ話者の連続台詞、連続する地の文、同じ原文の次ページでは、テキストボックスを
  消さずに本文だけを次の文章へ入れ替えます。
- 別の人物への交代、地の文と人物の切り替え、主人公の中央ボックスとの切り替えでは、
  メインのテキストボックスを約140ミリ秒で消してから次の表示へ切り替えます。
- `???`から`クロコ`への名前登録は同じ`speakerId`を持つ人物として扱い、
  `???`を500ミリ秒で完全に消し、空の名前欄を150ミリ秒保ってから、
  `クロコ`を500ミリ秒で表示します。名前欄の枠と本文ボックスは消しません。
- 文章は1文字45ミリ秒の速さで、1文字ずつ表示します。
- 文章の表示が終わると、右下に次へ進めることを示す印を表示します。
- 読み上げソフトには1文字ずつではなく、全文の表示完了後に文章全体を伝えます。

### 主人公の台詞ボックス

- 主人公の台詞は、画面中央の選択肢風ボックスに表示します。
- PC表示では画面幅72%とし、ボックスの高さ、文字、角丸も画面全体と同率で縮小します。
- 横長で角ばった長方形を、端末サイズにかかわらず同じ比率で保ちます。
- 1つのボックスは1行固定とし、長い台詞は文意を変えず最大2つに分けます。
- 主人公の台詞を表示している間は、画面全体ではなく台詞ボックス内だけをタップ判定にします。
- 2つ表示した場合はどちらを押しても同じ次の場面へ進み、押したボックスだけを約150ミリ秒で少し拡大してから、約270ミリ秒でフェードアウトします。
- 選ばなかったボックスは同時にフェードを開始し、約220ミリ秒で選んだボックスより先に消します。
- 押した瞬間に`static/audio/se/decision.mp3`を再生し、合計約420ミリ秒の演出後に次へ進みます。
- 主人公の台詞ボックスは、ホバー時やキーボードでフォーカスしたときも色や輪郭を変えません。
- macOSの「視差効果を減らす」が有効な場合も、主人公の台詞ボックスの決定演出は約420ミリ秒で再生します。
- 主人公の台詞ボックスには、次へ進むことを示す逆三角形を表示しません。
- PCではTabキーでボックスを移動し、EnterキーまたはSpaceキーで選べます。
- 読み上げソフトには、分割前の台詞全体を主人公の台詞として伝えます。

### 文章を進める操作

通常の台詞と地の文は、次の操作で文章を進めます。

- 画面のタップ
- マウスのクリック
- Enterキー
- Spaceキー

文章を表示している途中で操作した場合は、残りの文字をすぐにすべて表示します。
全文が表示された状態でもう一度操作すると、次の文章へ進みます。
主人公の台詞を表示している間は、上記の画面全体の操作を無効にし、中央の
台詞ボックスだけを使用します。
スマホでは通常文の文章送りボタンのタッチハイライトを無効にし、タップ時に画面が
黒く点滅しないようにします。主人公の台詞ボックスの決定演出はそのまま表示します。

## 音響演出

### メトロノームBGM

- 使用音源は`static/audio/bgm/metronome.mp3`です。
- 最初の文章「夢見るままに……」を表示するときからループ再生します。
- 再生開始時の音量は7%です。
- 約5秒かけて、音量を38%まで徐々に大きくします。
- 本編の読み込み時にブラウザが自動再生を拒否した場合は、最初のタップ、クリック、Enterキー、Spaceキーで再生を再試行します。
- 1曲目カード前の暗転と同時に、約1.5秒かけて音量を0にして停止します。
- 完全な黒画面と音量0になってから、曲名カードを表示します。

### BGMの音量制御

- タイトルと本編のBGMは、`src/ts/audio-gain-controller.ts`（Vite ビルドで `dist/assets/` へ出力）の`GainNode`で音量を変えます。
- Web Audio APIを利用できない場合は、`HTMLAudioElement.volume`へ切り替えます。
- iPhoneのChromeなどで音声処理が停止している場合は、タップ、クリック、Enterキー、Spaceキーの入力時に再開します。
- SEはBGM用の`GainNode`を通さず、各音源に設定した音量で再生します。

### 泡SEと背景切り替え

- 使用音源は`static/audio/se/bubble.mp3`です。
- 7番目から8番目の文章へ進むときに再生します。
- 泡SEが実際に再生を始めるのを待ってから、背景切り替えと泡の表示を開始します。
- 音声再生の開始待ちは最大400ミリ秒とし、再生できない場合も画面演出は続けます。

### キャンセルSEと決定SE

- キャンセルSEには`static/audio/se/cancel.mp3`を使用します。
- 元のMP3ファイルは変更せず、ブラウザでの再生音量を80%にします。
- 決定SEには`static/audio/se/decision.mp3`を使用します。
- 音声を再生できない場合も、画面操作や画面遷移を停止させません。

### クロコ初登場の革靴SE

- 使用音源は`static/audio/se/footsteps.mp3`です。
- クロコが初めて表示されるときだけ、音源の先頭から音量80%で再生します。
- 立ち絵を約1.5秒でフェードインし、足音は2秒後に停止して先頭へ戻します。
- 登場開始から2秒間は文章送りを無効にし、登場演出が終わってから主人公の台詞を操作可能にします。
- SEを再生できない場合も、立ち絵のフェードと2秒後の進行再開は実行します。

## 水中背景の切り替え

- 1番目から7番目までは、暗い水中背景を表示します。
- 8番目の「チクタク、チクタク」へ進むとき、明るい水中背景への切り替えを開始します。
- 暗い背景の上に明るい背景を重ね、約3秒かけて明るい背景の透明度を上げます。
- 切り替えには`ease-in-out`を使用し、急に画像が入れ替わって見えないようにします。
- 背景切り替え、泡SE、小さな泡の上昇は、同じタイミングで開始します。

### 小さな泡の演出

- 直径2pxから6pxの小さな泡を7個表示します。
- 泡は画面中央付近の下側から、約2.6秒から3.1秒かけて上昇します。
- 泡ごとに位置、大きさ、速度、左右への移動量を少し変えます。
- 透明度を低くし、文章や背景を目立たなくしない程度に表示します。
- 動きの最初と最後は透明にし、急に現れたり消えたりして見えないようにします。
- この演出は背景が明るくなる場面で一度だけ実行します。

## 1曲目の曲名カード

10番目の文章を読み終え、次へ進む操作をすると、画面中央に次の内容を表示します。

```text
1曲目
基礎練・ダイジェスト
```

- テキストボックスは非表示にします。
- 曲名カードは約1秒かけて滑らかに表示します。
- 画面全体の文章送り操作を一時的に無効にします。
- 1曲目の楽曲は再生しません。
- 先に海背景とメトロノームBGMを1.5秒で消し、完全な黒画面でカードを約1秒かけて表示します。
- カードを5秒表示した後、1.2秒で消してから音楽室を1.5秒で明転します。
- 左上の「タイトルへ」は引き続き使用できます。

## 1曲目後から2曲目

- 背景に`static/images/background/music_room.png`を使用し、昼過ぎの明るさを残します。
- クロコは画面中央へ、頭から腰付近までが大きく見えるように表示します。
- 初めて表示するときは、革靴SEと同時に約1.5秒かけて滑らかにフェードインします。
- 立ち絵を2枚重ね、台詞に合わせて`default`、`smirk`、`smile`、`grin`の表情を
  切り替えます。新しい表情を後ろへ不透明で置き、古い前面だけを約600ミリ秒で消します。
- 表情画像を事前に読み込み、デコードが終わってから透明度を
  `cubic-bezier(0.4, 0, 0.2, 1)`で変化させます。
- 古い表情のフェード中は次の文章送りを無効にし、途中で別の表情へ差し替えません。
- 表情画像を読み込めない場合は直前の表情を残し、物語の進行は停止しません。
- 「クロコ。登録しました。」の表示後は文章送りを一時無効にし、`???`と`クロコ`を
  順番に切り替えます。`???`を500ミリ秒で消し、空の名前欄を150ミリ秒保ち、
  `クロコ`を500ミリ秒で表示します。立ち絵は同時に`grin`へ切り替えます。
- 切り替え後、「なかなか愛嬌のある名前です」を自動で表示します。
- 「急に責任が重い。」「うーん……」「じゃあ、クロコ」は、1個ずつ3画面に分けて表示します。
- クロコ登場後の「やっぱり誰かいた。さっきから話しているあなたは誰？」を選び終えると、`static/audio/bgm/corridor.mp3`の「朝日溢れる回廊_2」を4秒かけて音量34%まで上げ、ループ再生します。
- 選択タップ時に音量0で再生を始め、ブラウザの音声再生許可を確保してから選択演出後にフェードインします。
- 最後の案内を読み終えると、朝日BGMと画面全体を1.5秒で黒く暗転し、完全な黒画面でBGMを停止して先頭へ戻します。
- 完全な黒画面に「2曲目　過去の音楽劇メドレー」のカードを1秒で表示し、その後に5秒の自動進行を開始します。
- カードを1.2秒で消した裏で背景を`static/images/background/hole.png`へ交換し、2曲目後の場面を1.5秒で明転します。
- 暗転開始から明転完了までは、タイトル操作を含む入力を無効にします。
- カード上では、タップ、クリック、Enterキー、Spaceキーによる手動進行を受け付けません。

## タイトルへ戻る操作

- 本編の左上に「タイトルへ」ボタンを常に表示します。
- 上端と左端からそれぞれ`1.25cqw`の位置へ置き、本文と同じ`1.85625cqw`の文字で表示します。
- 余白は上下`0.25em`、左右`0.6em`とし、スピーカーボタンと同じ程度まで左上へ寄せます。
- マウスを重ねても色や大きさを変えません。キーボード操作に必要なフォーカス表示は残します。
- 文章の途中や、1曲目・2曲目の曲名カードを表示した後でも使用できます。
- 「タイトルへ」を押すとキャンセルSEを鳴らし、確認画面を表示します。
- 確認画面には、次の内容を表示します。

```text
タイトルに戻りますか？
現在の進行は失われます。

キャンセル　タイトルに戻る
```

### キャンセルする場合

- 「キャンセル」またはEscapeキーで確認画面を閉じます。
- 確認画面を閉じるときも、キャンセルSEを再生します。
- 逐次表示の途中で確認画面を開いた場合は、その位置で表示を停止し、閉じた後に続きから再開します。
- 1曲目カードの5秒待機中に確認画面を開いた場合はタイマーを停め、閉じた後に残り時間から再開します。

### タイトルに戻る場合

- 「タイトルに戻る」を押すと、決定SEを再生します。
- 泡SE、メトロノームBGM、朝日BGMを停止します。
- 決定SEが最後まで鳴ってから、タイトル画面`/`へ戻ります。
- 決定SEを再生できない場合、または音源の読み込みが止まった場合は、最大2.5秒で待機を終えてタイトルへ戻ります。
- 復帰処理中は各ボタンを無効にし、二重操作を防ぎます。

## 動きを減らす端末設定

次の演出は物語の進行と操作結果を伝えるために必要なので、macOSなどで
「視差効果を減らす」が有効でも指定時間のまま表示します。

- 本編開始時の約1.5秒のフェードイン
- 水中背景の約3秒のクロスフェード
- 背景切り替え時の小さな泡
- 主人公の台詞を選んだときの約420ミリ秒の演出
- 1曲目前の1.5秒の暗転、カードの1秒の登場・1.2秒の退場、次場面の1.5秒の明転
- クロコ初登場時の1.5秒のフェードと2秒の入力停止
- 2曲目前の1.5秒の暗転、カードの1秒の登場・1.2秒の退場、次場面の1.5秒の明転

通常の文章ボックスの切り替え、クロコが退場するときの短いフェード、表情の
クロスフェードも含め、端末設定による時間の短縮は行いません。

## シナリオデータと再生処理

- ブラウザで使用する台詞は`static/data/scenario.json`と再生処理を正とし、
  `script.md`は現在の実装に合わせて更新します。
- ブラウザで再生する範囲は`static/data/scenario.json`へ登録します。
- `sourceText`には原文を保存し、2画面へ分ける通常文は`pages`、主人公の
  1個または2個のボックスは`lines`へ指定します。
- 発話台詞には人物を識別する`speakerId`を指定し、表示名ではなくこのIDで
  テキストボックスの切り替えを判断します。
- `src/ts/scenario-runtime.ts`は、画面に依存せず台詞、ページ、章の順番を管理します。
- 入力状態は`game-state-controller.ts`、文字送りは`game-dialog-view.ts`、演出IDは
  演出カタログとランナーが担当し、`game.ts`が背景、立ち絵、BGM、SE、暗転を接続します。
- `src/ts/audio-gain-controller.ts`は、BGMのフェードとWeb Audio APIを利用できない場合の切り替えを担当します。
- JSONの読み込み失敗や、未知の背景・表情・演出IDがある場合は進行を止め、
  本編画面に原因を表示します。

## 読み上げとキーボード操作

- HTMLの言語は日本語にします。
- 装飾用の背景、光、微粒子、泡、飾り線は読み上げません。
- 本編の文章送りと主人公の台詞選択には実際の`button`要素を使用します。
- 確認画面を開いている間は、Tabキーの移動を2つの確認ボタン内に保ちます。
- Escapeキーで確認画面を閉じられるようにします。
- 外部フォント、外部JavaScriptライブラリ、通信が必要な素材は使用しません。

## 確認方法

詳細な開発環境・テスト手順は [development.md](../development.md) を参照します。

### 開発サーバーを起動する

```sh
nix develop
npm ci
npm run dev
```

ブラウザで`http://127.0.0.1:5001`を開きます。

### 自動テスト

```sh
npm run typecheck
npm run build
npm run test:unit
npx playwright test
```

自動テストでは、次の内容を確認します。

- `/game.html`（開発時は `/game` も可）を正常に表示できること
- 必要な背景画像、立ち絵、SE、BGM、JavaScriptモジュールを取得できること
- 長文の`pages`と主人公台詞の`lines`を連結すると原文へ戻ること
- 本編冒頭が全10画面になり、1曲目カードへ進むこと
- 1曲目カードから5秒後に1曲目後へ進むこと
- 1曲目後の最後から、5秒後に自動で後半へ進む2曲目カードへ到達すること
- 未知の演出IDや3個以上の主人公台詞ボックスを開始前に拒否すること
- 「視差効果を減らす」による演出時間の変更がCSSにないこと
- 667×375、844×390、1920×1080で画面全体が収まり、確認画面とENDまで操作できること

### ブラウザと実機で確認する項目

- 667×375、844×390、1920×1080で本編の表示が画面内に収まること
- 最初の文章が表示される時点で、メトロノームが聞こえること
- メトロノームの音量が徐々に大きくなること
- 本文が2行の範囲に収まり、1文字ずつ表示されること
- 主人公の台詞が1行のボックス最大2つに収まること
- 主人公の台詞以外の場所を押しても進まず、どちらの台詞ボックスを押しても同じ次の場面へ進むこと
- 押した主人公の台詞が少し膨らんで消え、選ばなかった台詞がそれより先に消え、同時に決定SEが鳴ること
- 海背景とメトロノームが1.5秒で消え、1曲目カードが1秒で現れ、5秒後にカードが1.2秒で消えて音楽室が1.5秒で現れること
- メトロノームBGMが音楽室への切り替え時に徐々に停止すること
- クロコが革靴SEとともに中央へ1.5秒でフェードインし、2秒間は操作できないこと
- クロコ登場後の最初の主人公台詞を選ぶと、朝日BGMが4秒で音量34%まで上がること
- 新しい表情が半透明にならず、前にある古い表情だけが滑らかに消えること
- 名前登録時に`???`が完全に消え、空の名前欄を挟んで`クロコ`が現れること
- 名前登録演出中も名前欄の枠と本文ボックスが消えないこと
- 音楽室と朝日BGMが1.5秒で暗転し、2曲目カードが1秒で現れ、5秒後にホール背景が1.5秒で明転すること
- 2曲目カードの明転完了後、手動操作を受け付けず5秒後に後半へ進むこと
- 泡SE、背景のクロスフェード、小さな泡が同じタイミングで始まること
- 小さな泡が目立ちすぎず、下から上へ移動すること
- 「タイトルへ」「キャンセル」「タイトルに戻る」の音と動作が正しいこと
- 「タイトルへ」にマウスを重ねても見た目が変わらず、キーボードのフォーカスは確認できること
- スマホで通常文を進めるためにタップしても、押した範囲が黒く点滅しないこと
- 縦向きでも16:9のゲーム画面全体が表示されること
