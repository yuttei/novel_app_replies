# 開始画面仕様

更新日：2026年11月21日

## 目的

ゲームを開いたプレイヤーに、作品名と音楽室の風景を最初に見せる画面です。

夕方の音楽室に光と微粒子を重ね、静止画のままに見えないようにします。画面を派手に動かすことより、数秒見れば変化に気づける程度の演出を優先します。

## 表示場所

- URL：`/`（`index.html`）
- HTML：`index.html`
- CSS：`static/css/title.css`
- TypeScript：`src/ts/title.ts`（Vite ビルドで `dist/assets/` へ出力）
- 背景画像：`static/images/background/music_room.png`
- ブラウザアイコン：`static/images/icons/`
- タイトルBGM：`static/audio/bgm/title.mp3`
- 決定SE：`static/audio/se/decision.mp3`

`img_background/music_room.png` は元画像として残し、配信用画像は `static/images/` に配置したものを使います。外部音源の管理方針は [assets-policy.md](../assets-policy.md) を参照します。

## 画面比率

- ゲーム画面は16:9で固定します。
- 1600×900のPC表示を基準にし、スマホでは背景、タイトル、ボタン、装飾を同率で縮小します。
- 端末の画面が16:9より横長の場合は、高さに合わせて左右へ暗い余白を入れます。
- 縦向きの場合は、16:9のゲーム画面全体を縮小して中央に表示します。横向きにするよう促す画面は出しません。
- `viewport-fit=cover` と `safe-area-inset` を使い、ノッチやホームインジケーターとの重なりを避けます。
- 画面外へのスクロールは発生させません。

## 背景

第1音楽室を想定した `music_room.png` を、画面いっぱいに表示します。画像自体は移動させません。

CSSで暖色と暗いグラデーションを重ね、夕方の音楽室に見えるよう調整します。画面周辺は中央より暗くし、タイトルを読みやすくします。

### レイヤーの順番

背景側から、次の順番で重ねます。

1. `.stage-background`：音楽室の背景画像
2. `.stage-tint`：夕方の色と周辺の暗さ
3. `.sunset-light`：窓から差し込む夕焼けの光
4. `.sunset-dust`：光の中を漂う微粒子
5. タイトルと `tap to start`
6. 左上のスピーカーアイコン
7. 右下の音源クレジットボタンとクレジット画面
8. ゲーム開始時に画面を覆う黒い幕

夕焼けと微粒子は装飾です。HTMLでは `aria-hidden="true"` を指定し、読み上げソフトの対象から外します。

## タイトル

- 表示文字は「青春再演劇場」と「リプライズ」の二段です。
- タイトル全体の中心を、画面の上から42%の位置へ置きます。画面中央より少し上です。
- 日本語の明朝体を優先して表示します。
- 文字色は生成り色と金色を使い、暗い影を付けます。
- 「青春再演劇場」の大きさは、16:9のゲーム画面幅に対する`9cqw`を基準とします。
- 「リプライズ」の大きさは、16:9のゲーム画面幅に対する`4.3875cqw`を基準とします。
- 二段のタイトルの下に、金色の細い飾り線を表示します。

タイトルを含む各要素は、1600×900の画面幅を基準とした`cqw`で指定します。スマホでもPCと同じ配置と比率のまま縮小します。

## ブラウザアイコン

- ブラウザのタブには、暗い茶黒の背景へ金色のメトロノームを配置したアイコンを表示します。
- メトロノームの周囲の円弧で、時間の繰り返しと「リプライズ」を表します。
- タイトル画面と本編画面は、同じfaviconを参照します。
- 通常のブラウザ向けに16、32、48ピクセルを含む`favicon.ico`と32ピクセルのPNGを用意します。
- 高解像度表示向けに512ピクセルのPNG、iPhoneのホーム画面向けに180ピクセルのApple Touch Iconを用意します。
- 文字や人物は入れず、小さく表示してもメトロノームの輪郭が分かる構図にします。

## タイトルBGMとスピーカーアイコン

- 「私は口を閉ざす」を音量30%でループ再生します。
- ページを表示したときに自動再生を試します。
- ブラウザに自動再生を拒否された場合は、左上のスピーカーアイコンを停止状態で表示します。
- スピーカーアイコンを押すとBGMを再生し、もう一度押すと一時停止します。
- 一時停止後は、同じ再生位置から再開します。
- アイコンを押した操作はゲーム開始処理へ伝えず、BGMの状態だけを変更します。
- 自動再生に成功した場合は音が出ているアイコン、停止中は斜線付きアイコンを表示します。
- 読み上げソフト向けに、状態に応じて「BGMを再生」「BGMを一時停止」と伝えます。
- スピーカーボタンの直径は`3.75cqw`、アイコンは`2cqw`とし、スマホでもゲーム画面と同じ倍率で縮小します。

BGMの音量変更にはWeb Audio APIの`GainNode`を使います。利用できない場合は
`HTMLAudioElement.volume`へ切り替えます。iPhoneのChromeなどで音声処理が停止している場合は、
スピーカーボタンや開始操作を押したときに再開します。SEはBGMとは別に、音源の音量で再生します。

一般的なWebページには、マイクやカメラのようなBGM自動再生用の許可画面を
ページ側から表示する仕組みがありません。そのため、実際のユーザー操作で再生できる
スピーカーアイコンを、自動再生が拒否された場合の正式な再生手段とします。

## tap to start

- 表示文字は小文字の `tap to start` です。
- 枠、背景色、角丸、座布団状の装飾は付けません。
- 画面下から14%の位置へ置きます。
- 3.8秒かけて、透明度8%から100%まで明るくなり、再び薄くなる動きを繰り返します。
- キーボードでフォーカスした場合は、細い金色の輪郭を表示します。
- マウスとタッチ操作では、`tap to start` の文字部分だけでなく、16:9のゲーム画面内の
  どこを押しても同じ開始処理を実行します。
- タッチ時のブラウザ標準ハイライトを無効にし、押した範囲が黒く点滅しないようにします。

ボタンを押すと決定SEが鳴り、画面が約1.8秒かけてフェードアウトします。
タイトルBGMが再生中の場合は、同じ1.8秒で音量を0まで下げて停止し、先頭へ戻します。
利用者がBGMを一時停止している場合は、ゲーム開始時に勝手に再生しません。
決定SEとフェードアウトの両方が終わってから、本編画面 `/game.html`（開始画面からは `./game.html` へ遷移）へ移動します。
本編は黒い画面から約1.5秒かけてフェードインし、その後に最初の文章を表示します。

SEがブラウザの設定などで再生できなかった場合も、暗転と本編への移動は続けます。
一度押した後はボタンを無効にし、連打によるSEの重複や二重遷移を防ぎます。

## 音源クレジット

- 画面右下に「音源クレジット」ボタンを表示します。
- ボタンを押すと、DOVA-SYNDROME、OtoLogic、効果音ラボの素材名と制作者を確認できます。
- OtoLogicは`CC BY 4.0`の条件に従い、公式サイトへのリンクとともに表示します。
- クレジットの下部に「音源の利用について」を横幅いっぱいで表示し、音源の著作権が制作者と配布元にあることと、ゲーム内から音源ファイルを抽出してプレイ以外の用途へ利用・再配布することの禁止を明記します。
- クレジット内のリンクは新しいタブで開きます。
- クレジットを開閉してもタイトルBGMは止めません。
- クレジット内のボタンやリンクを押しても、ゲーム開始処理は実行しません。
- 閉じるボタンまたはEscapeキーで閉じ、キーボード操作時はクレジットボタンへ戻ります。

## アニメーション

### 最初の登場

- 背景は800ミリ秒かけて表示します。
- タイトルはページを開いてから200ミリ秒待ち、650ミリ秒かけて表示します。
- タイトル下の飾り線は350ミリ秒待ってから、650ミリ秒かけて表示します。

### 夕焼け

- 右側の窓から室内へ差し込む、ぼかした光をCSSで作ります。
- 光は画面幅の約12%を移動します。
- 左から右へ移動して元の位置へ戻るまでを8秒とし、この動きを繰り返します。
- 移動に合わせて光の透明度と大きさも少し変えます。
- 光は暗い色調レイヤーより手前へ置き、移動が分かる明るさを確保します。

### 微粒子

- 光が当たる右側を中心に、合計15個の微粒子を表示します。
- 手前の8個は少し大きく明るくし、10秒かけて斜め上へ移動します。
- 奥の7個は小さく淡くし、14秒かけて手前より狭い範囲を移動します。
- 二つの動きには異なる開始位置を設定し、同時に現れて同時に消えないようにします。
- 粒子は移動の最初と最後に透明になり、繰り返し部分が急に切り替わって見えないようにします。
- `mask-image` を使い、光の外側や画面端では粒子を見えなくします。Safari向けに `-webkit-mask-image` も指定します。

夕焼けと微粒子には画像やJavaScriptを使いません。CSSのグラデーションとアニメーションだけで表示します。

## 動きを減らす設定

端末で「視差効果を減らす」が有効な場合も、背景、タイトル、飾り線、夕焼け、
微粒子、`tap to start`、本編への1.8秒のフェードアウトを指定時間のまま表示します。
決定SEが再生できた場合は、SEが鳴り終わるまで本編へ移動しません。

## 読み上げと操作

- HTMLの言語は日本語にします。
- ゲーム画面は `aria-labelledby="game-title"` でタイトルと関連付けます。
- 背景、夕焼け、微粒子、飾り線は読み上げません。
- `tap to start` には実際の `button` 要素を使い、クリックやキーボードで操作できるようにします。
- スピーカーアイコンにも実際の`button`要素を使い、現在の再生状態を`aria-pressed`で伝えます。
- スピーカーアイコンを押しても、親要素のゲーム開始操作は実行しません。
- 音源クレジットには`dialog`要素を使い、表示中は背後の開始画面へフォーカスを移しません。
- 外部フォント、JavaScriptライブラリ、通信が必要な素材は使いません。

## 本編への接続

- 本編のURLは `/game.html`（開始画面からは `./game.html` へ遷移、開発時は `/game` も可）です。
- タイトル画面を黒くした後、`/game.html` を黒画面から約1.5秒で表示します。
- 本編の入力、文章、立ち絵、BGM、曲名カードの仕様は[ゲーム冒頭仕様.md](ゲーム冒頭仕様.md)を参照します。
- 現在遊べる範囲と未実装項目の一覧は[実装済み仕様.md](実装済み仕様.md)を参照します。

## 確認方法

開発環境へ入り、Vite 開発サーバーを起動します。

```sh
nix develop
npm ci
npm run dev
```

表示された `http://127.0.0.1:5001` をブラウザで開きます。CSSを変更した直後に古い表示が残る場合は、`Command + Shift + R` で再読み込みします。

### 自動テスト

詳細なテスト実行手順は [development.md](../development.md) を参照します。

```sh
npm run typecheck
npm run build
npm run test:unit
npx playwright test
```

現在のテストでは、次の内容を確認しています。

- `/` が正常に表示されること
- タイトルと `tap to start` がHTMLに含まれること
- タイトルBGMとスピーカーボタンがHTMLに含まれること
- 音源クレジットボタン、ダイアログ、OtoLogicの必須表記、音源の抽出・別用途利用の禁止文言がHTMLに含まれること
- `tap to start` が本編へ接続されていること
- 開始画面のゲーム画面全体が開始操作に接続されていること
- スピーカーボタンの操作がゲーム開始処理へ伝わらないこと
- タイトルBGMの自動再生試行、音量30%、ループ、開始時のフェードアウトが設定されていること
- BGMの音量変更に`GainNode`を使い、利用できない環境向けの処理があること
- 背景画像、タイトルBGM、決定SE、CSSを取得できること
- 夕焼け、微粒子、`tap to start` のアニメーションがCSSに含まれること
- 夕焼けが8秒、手前の粒子が10秒、奥の粒子が14秒に設定されていること
- 実ブラウザ（Playwright）で3種類の画面サイズ表示と本編への遷移が動作すること

### ブラウザで見る項目

- 667×375と844×390で、タイトルと `tap to start` が切れないこと
- 1920×1080で、タイトルが画面中央より少し上に見えること
- 1〜2秒見れば、光か微粒子の変化に気づけること
- 微粒子がタイトルの読みやすさを邪魔しないこと
- 縦向きでも16:9の画面全体が表示されること

- スピーカーアイコンを押しても本編へ移動しないこと

- 再生中と停止中でスピーカーアイコンが切り替わること

- 決定SEと暗転の終了後に本編へ移動すること
